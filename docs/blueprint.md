# **App Name**: SuperiorStrength Tracker

## Core Features:

- Exercise Listing: Display a customizable list of upper body exercises (e.g., Pull-ups, Bench Press, Shoulder Press).
- Sets & Reps Input: Enable users to input and update sets and repetitions for each exercise during a workout session.
- Local Data Saving: Persist the daily exercise tracking data locally within the browser to recall progress for the current session or day.
- Dark/Light Theme Toggle: Provide a toggle to switch between the light and dark visual themes, with styles managed in CSS :root variables.
- Multilingual Support: Implement a toggle for language switching between English and Spanish, dynamically updating all relevant UI text using a JavaScript JSON object.

## Style Guidelines:

- Light theme primary color: Energetic red (#E53935) for actions and highlights. Background color: Clean white (#FAFAFA). Secondary accent color: Vibrant raspberry pink (#E56B99).
- Dark theme primary color: Bold red (#EF5350) for intensity. Background color: Deep charcoal (#121212). Secondary accent color: Bright light pink (#F49FC0) for contrast.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, slightly technical aesthetic. Body text font: 'Inter' (sans-serif) for excellent readability and data entry.
- Utilize simple, line-art style icons for exercises, settings toggles (theme, language), and interactive elements to maintain a minimalist and functional appearance.
- Implement a mobile-first, responsive layout using a card-based structure for individual exercises. Key controls like theme and language toggles will be easily accessible in a dedicated header or footer.
- Incorporate subtle ease-in-out transitions for theme and language switching, and minimal hover feedback on clickable elements to enhance user interaction without distraction.
